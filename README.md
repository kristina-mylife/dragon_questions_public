# Dragon Questions — landing page

Static landing page for [Dragon Questions](https://t.me/dragon_questions_bot), served by GitHub Pages at
https://kristina-mylife.github.io/dragon_questions_public/

One file, `index.html`: HTML and CSS, no JavaScript, no trackers, no cookies. Fonts come from Google Fonts.
The favicon is an inline SVG, so the page has no other assets and works under the `/dragon_questions_public/` subpath.

## Publish

1. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
2. Branch: **main**, folder: **/ (root)** → Save.
3. The site is live at the URL above within a minute or two.

`.nojekyll` turns off Jekyll processing; the page is served as is.

The application code lives in a separate private repository and is not part of this site.
